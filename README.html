📈 Traffic Catcher

실시간 이슈·방송·시즌·주식·문화·OTT 트렌드 모니터링 및 콘텐츠 스튜디오 설명서

네이트, 다음, 줌, 시그널(Signal.bz)의 실시간 키워드와 인기 주식, 주간 방송 편성·시청률, 축제·행사, 개봉 영화, 공연, Netflix 주간 Top 10을 수집합니다. Google Gemini와 Google News RSS·YouTube Data API v3를 연동해 기사와 쇼츠 4컷을 생성합니다.

⚙️ 시스템 아키텍처 (Architecture)

본 시스템은 사용자의 인프라에 맞춰 두 가지 실행 방식을 유연하게 선택할 수 있도록 하이브리드 설계되었습니다.

1. 로컬 구동 모드 (Flask Web Server)

로컬 PC에서 python portal_crawler.py --web 명령으로 웹 서버를 띄워 실시간 수집을 컨트롤하고 확인합니다.

로컬 실행 ➔ Flask 웹 서버 구동 ➔ BeautifulSoup & API 크롤링 구동 ➔ CSV 누적 저장 ➔ 웹 대시보드 출력
2. 클라우드 서버리스 모드 (GitHub Actions & Cloudflare)

로컬 컴퓨터를 꺼두어도 GitHub Actions가 KST 06:17~23:17에 매시간 수집하고 Cloudflare Pages가 변경된 정적 데이터를 자동 배포합니다.

GitHub Actions (KST 06:17~23:17 매시간) ➔ portal_crawler.py 실행 ➔ JSON·CSV 갱신 ➔ GitHub 자동 푸시 ➔ Cloudflare Pages 자동 배포

✨ 핵심 기능 (Features)

  • 네이트(Nate) 실시간 키워드 수집: 메인 페이지의 AI 이슈 키워드(Top 5) 및 상승/하락 변동 지표를 파싱합니다.
  • 다음(Daum) 실시간 트렌드 수집: 모바일 메인 페이지에서 10분 간격으로 급상승하는 10개 트렌드 키워드와 순위 변동 수치를 안정적으로 파싱합니다.
  • 줌(Zum) AI 이슈 검색어 수집: 줌 메인에 심어진 Next.js 직렬화 스트림 코드를 해독하여 실시간 인기 이슈(Top 10) 및 요약 질문을 파싱합니다.
  • 시그널(Signal) 실시간 검색어 수집 [NEW]: signal.bz의 핵심 API인 https://api.signal.bz/news/realtime과의 다이렉트 통신을 통해 실시간 인기 키워드 1~10위 정보와 변동 상태를 정밀 JSON 수집합니다.
  • 줌(Zum) 인기 주식 데이터 연동: 급상승 주식 25개의 현재가, 종목코드, 등락률과 데이터 기준 시각을 표시합니다. 제목부터 표 데이터까지 Noto Sans KR 서체와 일관된 굵기·숫자 간격을 사용합니다.
  • Zum Top 10 무결성: 키워드는 수집과 화면 렌더링에서 최대 10위까지만 표시하고 상승·하락·동일 정보와 실제 순위를 분리합니다.
  • 4대 포털 교차 유사도 분석 (Cross Trending) [NEW]: 시그널, 다음, 네이트, 줌에서 2개 이상 포털에 동시 급상승 중인 키워드를 실시간 탐지하고 ⚡ 2사 일치, 🔥 3사 일치, 👑 4사 올킬 뱃지 및 마우스 오버 연쇄 발광 효과를 부여합니다.

🔑 외부 API Key 설정

서버 수집 키는 로컬 .env와 GitHub Actions Repository Secret에 저장하고, 브라우저 전용 Gemini·YouTube 키는 현재 브라우저의 localStorage에만 저장합니다. 키를 HTML·Python·JSON 또는 Git 커밋에 직접 기록하지 않습니다.

  • TourAPI: TOUR_API_SERVICE_KEY — 축제·행사 수집
  • KOBIS: KOBIS_API_KEY — 개봉 영화 수집
  • KOPIS: KOPIS_API_KEY — 공연 수집
  • Gemini 전용 키: Generative Language API를 활성화하고 Google AI Studio에서 발급합니다.
  • YouTube 전용 키: Google Cloud에서 YouTube Data API v3를 활성화한 프로젝트에서 별도로 발급합니다.
  • 웹사이트 제한: trafficcatcher.pages.dev, 127.0.0.1, localhost를 실제 사용 환경에 맞춰 허용합니다.

✨ AI로 기사 보완하기

완성 기사에서 빠진 정보나 수정할 사실을 입력하면 Gemini가 기존 기사 전체와 요청을 함께 분석해 문맥에 자연스럽게 통합합니다. Google·YouTube 검색은 반복하지 않고 기존 Fact Sources를 유지하며, 실패 시 원문을 보존합니다. 성공 후에는 수정 전으로 버튼으로 되돌릴 수 있습니다.

🚀 사용 설명서 (Usage Guide)

네이버 블로그 로컬 발행 도우미

기사 작성이 끝난 뒤 네이버 블로그로 보내기를 사용하려면 프로젝트 폴더의 실행_네이버블로그도우미.bat을 먼저 실행합니다. 도우미는 http://127.0.0.1:8765에서만 동작하며 원고를 로컬 SQLite에 저장하고 네이버 글쓰기 화면을 엽니다.

네이버 계정 정보와 쿠키는 Traffic Catcher로 전송하지 않습니다. 스마트에디터에 원고를 붙여넣은 뒤 최종 발행 또는 예약 발행은 사용자가 직접 확인합니다.

방법 A. 로컬 대시보드 실행하기

1. 필요한 파이썬 라이브러리들을 설치합니다.

pip install flask requests beautifulsoup4 pandas lxml google-genai

2. 실행_웹서버.bat을 실행합니다. 기동 즉시 1회 수집한 뒤 로컬에서는 15분 간격으로 자동 반복합니다.

실행_웹서버.bat

3. 인터넷 브라우저에서 http://127.0.0.1:5001로 접속합니다. 로컬 서버를 여러 개 실행하면 포트 충돌과 WinError 10013이 발생할 수 있으므로 하나만 실행합니다.

방법 B. 24시간 클라우드 자동 수집 배포 (GitHub Actions & Cloudflare Pages)

1. 제공된 소스 코드 전체를 본인의 깃허브(GitHub) 저장소에 푸시(Push)합니다.

2. 깃허브 Actions 쓰기 권한 활성화 (중요): 저장소 Settings ➔ Actions ➔ General ➔ Workflow permissions에서 Read and write permissions를 선택하고 저장합니다.

3. Cloudflare 대시보드에 로그인하여 Workers & Pages ➔ Create application ➔ Pages ➔ Connect to Git 버튼을 통해 깃허브 저장소를 선택합니다.

4. 빌드 설정 화면에서 다음과 같이 세팅한 후 배포합니다.

  • Framework preset: None
  • Build command: (공란으로 비워둠)
  • Build output directory: . (마침표 하나 입력)

5. 배포 완료 후 pages.dev 주소에서 확인합니다. 예약 수집은 KST 06:17~23:17에 매시간 동작하며 AUTO_CRAWL_ENABLED=false Repository Variable로 예약 실행만 중지할 수 있습니다.
