실시간 포털 트렌드 & 주식 및 시그널(Signal) 연동 수집기 설명서

포털 사이트(네이트, 다음, 줌) 및 네이버 실검 대체 서비스인 시그널(Signal.bz)의 실시간 급상승 키워드와 인기 주식 정보를 수집하고 가공하여 사용자에게 시각적으로 서빙해주는 자동화 크롤러 대시보드 시스템입니다.

⚙️ 시스템 아키텍처 (Architecture)

본 시스템은 사용자의 인프라에 맞춰 두 가지 실행 방식을 유연하게 선택할 수 있도록 하이브리드 설계되었습니다.

1. 로컬 구동 모드 (Flask Web Server)

로컬 PC에서 python portal_crawler.py --web 명령으로 웹 서버를 띄워 실시간 수집을 컨트롤하고 확인합니다.

로컬 실행 ➔ Flask 웹 서버 구동 ➔ BeautifulSoup & API 크롤링 구동 ➔ CSV 누적 저장 ➔ 웹 대시보드 출력
2. 클라우드 서버리스 모드 (GitHub Actions & Cloudflare)

로컬 컴퓨터를 완전히 꺼두어도 30분 주기로 자동 크롤링이 작동하고 Cloudflare Pages 도메인을 통해 전세계 어디서든 실시간 데이터가 갱신됩니다.

GitHub Actions (30분 주기 스케줄러) ➔ portal_crawler.py 실행 ➔ 데이터 갱신 후 깃허브 자동 푸시 ➔ Cloudflare Pages 자동 감지 및 웹 대시보드 배포

✨ 핵심 기능 (Features)

  • 네이트(Nate) 실시간 키워드 수집: 메인 페이지의 AI 이슈 키워드(Top 5) 및 상승/하락 변동 지표를 파싱합니다.
  • 다음(Daum) 실시간 트렌드 수집: 모바일 메인 페이지에서 10분 간격으로 급상승하는 10개 트렌드 키워드와 순위 변동 수치를 안정적으로 파싱합니다.
  • 줌(Zum) AI 이슈 검색어 수집: 줌 메인에 심어진 Next.js 직렬화 스트림 코드를 해독하여 실시간 인기 이슈(Top 10) 및 요약 질문을 파싱합니다.
  • 시그널(Signal) 실시간 검색어 수집 [NEW]: signal.bz의 핵심 API인 https://api.signal.bz/news/realtime과의 다이렉트 통신을 통해 실시간 인기 키워드 1~10위 정보와 변동 상태를 정밀 JSON 수집합니다.
  • 줌(Zum) 인기 주식 데이터 연동: 현재 줌 금융 섹션에서 검색량과 클릭률이 가장 높은 급상승 주식 종목 25개의 시세 정보(현재가, 종목코드, 등락률)를 연관 데이터로 함께 수집합니다.
  • 안정성 확보 및 차단 우회: 무작위 지연(Random Delay)과 브라우저 User-Agent 모방 헤더를 적용해 매크로 차단을 방지하며, 개별 포털 장애에 강한 상호 독립형 예외 처리 구조를 가집니다.
  • 한글 무결성 보장 CSV 누적: 수집 때마다 데이터에 시각 타임스탬프를 매겨 realtime_trends.csv 파일에 기록하며, 엑셀에서 바로 열 수 있도록 utf-8-sig 인코딩을 강제합니다.
  • 시그널 전용 독립 파일 저장 [NEW]: 시그널 수집 정보의 경우 사용자의 개별 파일 요건에 부합하도록 signal_realtime_keywords.csv 파일에 수집 일시, 순위, 키워드 컬럼 구조로 추가 분할 누적 저장됩니다.

🚀 사용 설명서 (Usage Guide)

방법 A. 로컬 대시보드 실행하기

1. 필요한 파이썬 라이브러리들을 설치합니다.

pip install flask requests beautifulsoup4 pandas lxml

2. 스크립트를 웹 서버 모드로 구동합니다.

python portal_crawler.py --web

3. 인터넷 브라우저를 열고 http://127.0.0.1:5000 주소로 접속합니다. 우측 상단의 [실시간 수집 실행] 버튼을 누르면 비동기로 크롤링이 진행되며 즉시 데이터가 화면과 두 종류의 CSV 파일에 업데이트됩니다.

방법 B. 24시간 클라우드 자동 수집 배포 (Cloudflare Pages)

1. 제공된 소스 코드 전체를 본인의 깃허브(GitHub) 저장소에 푸시(Push)합니다.

2. Cloudflare 대시보드에 로그인하여 Workers & Pages ➔ Create application ➔ Pages ➔ Connect to Git 버튼을 통해 깃허브 저장소를 선택합니다.

3. 빌드 설정 화면에서 다음과 같이 세팅한 후 배포합니다.

  • Framework preset: None
  • Build command: (공란으로 비워둠)
  • Build output directory: . (마침표 하나 입력)

4. 배포 완료 시 제공되는 전용 페이지 주소(pages.dev)를 통해 24시간 실시간 트렌드를 어디서든 확인할 수 있습니다. 깃허브 액션 스케줄러가 30분 마다 백그라운드에서 데이터를 알아서 갱신해 줍니다.
